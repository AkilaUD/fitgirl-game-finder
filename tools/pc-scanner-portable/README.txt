FitGirl PC Scanner (portable)

1. Generate a pairing code on https://fitgirl-game-finder.vercel.app (Scan my PC).
2. Double-click Run-Scanner.cmd (or run Scan.ps1 in PowerShell).
3. Enter the pairing code and confirm upload.
4. The browser tab should detect the scan within a few seconds.

Requires Windows 10/11 with WMI. No install — extract this zip anywhere and run.
